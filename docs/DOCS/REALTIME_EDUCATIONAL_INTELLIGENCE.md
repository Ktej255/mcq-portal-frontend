# Real-Time Educational Intelligence

Phase 18 introduces live educational cognition infrastructure. This layer moves from stored event analysis toward stream-aware session intelligence while preserving conservative, reversible, low-disruption safety boundaries.

## Real-Time Telemetry

Telemetry version: `realtime-telemetry.v1`

The real-time telemetry engine aggregates:

- heartbeat density
- current focus state
- pacing drift
- active hesitation
- confidence instability
- impulsive answering bursts
- session continuity score

Signals are probabilistic session evidence, not psychological diagnoses.

## Live Cognitive State

Live state detection estimates:

- emerging fatigue probability
- overload risk
- live instability
- pacing collapse
- hesitation spikes
- impulsive bursts
- confidence instability

The engine intentionally avoids persistent learner labels.

## Session Intelligence

Session version: `session-intelligence.v1`

The session engine combines:

- real-time telemetry state
- live cognitive-state probabilities
- historical pacing memory
- misconception memory
- current-session stability
- recovery attempts during the session
- live behavioral drift
- real-time conceptual struggle markers

## Live Orchestration

Live orchestration supports:

- observe-only decisions
- soft pacing buffers
- gentle recovery prompts
- brief reflection nudges

All live actions are:

- reversible
- explainable
- minimally disruptive
- policy-gated
- throttled

## Real-Time Governance

Live policy gates block stronger action when:

- telemetry is degraded
- signal confidence is low
- intervention frequency would be too high
- historical memory suggests pacing sensitivity

The system must never spam interventions or overreact to noisy telemetry.

## Educator Live Awareness

Educator awareness exposes:

- active session count
- unstable session count
- overload risk count
- telemetry degradation count
- subtle support alerts

This is educational support infrastructure, not surveillance.

## Low-Latency Foundations

The current implementation is service-layer and synchronous. It prepares for:

- async orchestration queues
- streaming event aggregation
- live policy gating
- throttled intervention frequency
- live observability channels

## Safety Boundaries

The platform must never:

- imply real-time psychological diagnosis
- present unstable signals as truth
- confuse transient struggle with persistent weakness
- create manipulative pressure
- create panic through live warnings

All live intelligence must remain conservative, reversible, explainable, and reliability-weighted.

## Remaining Risks

- Live event processing is not yet backed by a durable streaming queue.
- Intervention throttling is represented by policy output, not enforced by a persisted live decision log.
- Educator live awareness is service-ready but not UI-operational.
- No cohort-level aggregation table exists yet.
- Real-time thresholds need calibration against production telemetry.
